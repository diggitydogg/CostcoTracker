# Security

If you find a security or privacy issue in CostcoTracker, please do **not** post sensitive details in a public GitHub issue.

Examples include:

- exposed authentication/session data
- a way for backup files to leak information unexpectedly
- accidental logging of credentials or cookies
- a vulnerability that could expose another user's data
- committed secrets or tokens

Use GitHub's private vulnerability reporting feature if it is enabled for this repository.

If private vulnerability reporting is not available, open a minimal public issue saying that you found a security/privacy problem and need a private contact path. Do not include the sensitive details in the issue itself.

## Please do not send real Costco account data

When reporting a problem, do not include:

- passwords
- cookies
- session tokens
- full receipt histories
- backup files
- app databases
- unredacted Costco account screenshots
